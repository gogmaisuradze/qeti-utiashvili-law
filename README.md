# ქეთევან უტიაშვილის საადვოკატო ბიურო (Ketevan Utiashvili Law Office)

ქეთევან უტიაშვილის ოფიციალური საადვოკატო ბიუროს ვებ-გვერდი (თბილისი, ილია ჭავჭავაძის გამზ. #26).

## მახასიათებლები (Features)
- **სრული იურიდიული მომსახურება**: სამოქალაქო, კორპორაციული, უძრავი ქონების, საგადასახადო, ინტელექტუალური საკუთრებისა და სისხლის სამართალი.
- **ინტერაქტიული კალენდარი და ვიზიტის დაჯავშნა**: ადგილზე ვიზიტისა და ონლაინ კონსულტაციის ინტეგრირებული სისტემა.
- **საქმის ონლაინ დიაგნოსტიკა (Case Check)**: საქმის პერსპექტიულობის წინასწარი შეფასების კალკულატორი.
- **იურიდიული ასისტენტი (AI Legal Advisor)**: სწრაფი პასუხები პირველად სამართლებრივ შეკითხვებზე.
- **მრავალენოვანი მხარდაჭერა**: ქართული (GE) და ინგლისური (EN).
- **Gallant & Editorial Design System**: ბორდოსფერი (Imperial Bordeaux `#721927`), სუფთა ტიპოგრაფია (`Noto Serif Georgian`, `Inter`), მორგებული მობილურ და დესკტოპ მოწყობილობებზე.

## ტექნოლოგიები (Stack)
- HTML5 / CSS3 / Vanilla JavaScript
- FontAwesome Icons & Custom Hairline SVGs
- Google Fonts (`Noto Serif Georgian`, `Inter`, `Cinzel`)

## გაშვება (Getting Started)
პროექტის ლოკალურად გასაშვებად საკმარისია ნებისმიერი HTTP სერვერი:
```bash
python3 -m http.server 5500
```
შემდეგ გახსენით ბრაუზერში: `http://localhost:5500`
